📍 GAME LOCATION
   http://localhost:3000 → Click "Image Similarity" tile

🎮 HOW TO PLAY
   1. Select a reference image (🏠 🐱 🌳 😊 ☀️)
   2. Draw it on the canvas
   3. Click "Submit Drawing"
   4. Get your score (1-10)!

⚙️ TWO MODES

   Simple Mode (Default - No Setup Required)
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   $ npm run dev
   
   Works immediately with simplified scoring.

   Full Mode (Python Backend - More Accurate)
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   Terminal 1:
   $ cd python-backend
   $ ./setup.sh
   $ source venv/bin/activate
   $ python server.py
   
   Terminal 2:
   $ echo "PYTHON_BACKEND_URL=http://localhost:5000" >> .env.local
   $ npm run dev

🔍 SCORING ALGORITHMS (Full Mode)
   ✓ Structural Similarity (30%)
   ✓ Histogram Comparison (20%)
   ✓ Feature Matching (20%)
   ✓ Color Similarity (15%)
   ✓ Edge Similarity (15%)

💡 TIPS
   • Use different brush sizes for details
   • Try different colors to match prompts
   • Clear and redraw if needed
   • Practice makes perfect!

🔧 TROUBLESHOOTING
   Issue: Can't connect to Python backend
   → Check server is running: python server.py
   → Verify .env.local has PYTHON_BACKEND_URL
   
   Issue: Low scores for good drawings
   → Make sure Python backend is configured
   → Simple mode uses basic heuristics
